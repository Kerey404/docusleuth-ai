# Публикация DocuSleuth AI на GitHub Pages

Сайт полностью статический: GitHub Pages отдаёт файлы, а OCR и анализ выполняются в браузере посетителя. После публикации для показа достаточно открыть HTTPS-ссылку в Chrome или Edge. Интернет нужен для загрузки приложения, языковых пакетов и весов.

Подготовленная папка репозитория — `github-release/`. В неё включены браузерные файлы, веса, лицензии, код обучения и документация. Исходные корпуса, зависимости для обучения, промежуточные эксперименты и файлы соседних проектов не копируются.

Публикация настроена через `.github/workflows/pages.yml`: ветка `codex/github-pages`, артефакт `dist/`, окружение `github-pages`. В настройках репозитория раздел **Settings → Pages → Source** должен быть установлен в **GitHub Actions**. Официальные действия GitHub закреплены по SHA коммитов.

Бесплатный GitHub Pages для этого варианта использует открытый репозиторий. Файлы сайта и модельные веса будут публичны. Работы, которые посетитель загружает для проверки, приложение обрабатывает в его браузере; API загрузки работ отсутствует. Сам GitHub обслуживает сетевые запросы файлов сайта.

Локальный запуск через `Start-DocuSleuth.cmd` остаётся доступным. Ограничения моделей и некоммерческие условия KZ-данных описаны в `VALIDATION.md`; уведомления сторонних библиотек находятся в `dist/vendor/licenses/`.
